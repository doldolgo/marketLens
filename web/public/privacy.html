KimpTrack(운영: 고원규, 이진중 — 이하 “KimpTrack”)은 김프·역프를 보여 주는 무료 서비스입니다. 이 방침은 KimpTrack이 방문자에 대해 무엇을 기록하고, 어디로 보내며, 얼마 동안 두는지를 적습니다. 가입이 없어 이름·전화번호·결제 정보는 받지 않습니다.

화면 분석 거부

지금 상태

브라우저가 GPC를 보내는 동안은 분석하지 않습니다.

이 브라우저에는 선택을 저장할 수 없습니다. GPC·쿠키 차단·광고 차단기로도 거부할 수 있습니다.

[분석 거부]를 누르면 이 브라우저에 kt.analytics = denied를 저장하고, 이 사이트의 Clarity 쿠키 _clck·_clsk를 지웁니다. [다시 허용]은 granted를 저장합니다. 아무것도 고르지 않으면 허용으로 봅니다. 브라우저가 GPC(Global Privacy Control)를 보내면 저장값과 상관없이 분석하지 않습니다. 이 선택은 브라우저 안에서만 일어나 서버로 가지 않습니다.

kimptrack.com에서 고른 선택이 이 브라우저에 저장되고, 브라우저 데이터를 지우면 다시 골라야 합니다. 일부 브라우저(Safari 등)는 이 사이트를 7일 동안 쓰지 않으면 선택을 지웁니다 — 계속 거부하려면 GPC나 광고 차단기를 쓰세요.

새로 여는 페이지는 거부를 곧바로 따릅니다. 같은 브라우저에 이미 열린 kimptrack.com 랜딩·대시보드 탭은 거부를 누르는 순간 Clarity에 거부 신호를 보내 쿠키를 지우고, 그 탭을 다시 볼 때 한 번 새로고침되어 그때부터 분석하지 않습니다.

Microsoft 도메인의 쿠키(MUID 등)는 이 페이지가 지울 수 없습니다. Clarity가 안내하는 광고 거부 페이지 optout.aboutads.info(DAA)에서 따로 거부할 수 있습니다.

서버 접속 기록

kimptrack.com으로 온 요청마다 한 줄을 남깁니다: 시각, IP 앞부분(IPv4는 마지막 마디, IPv6는 뒤 80비트를 지움), 접속 포트, 프로토콜·메서드·호스트, 경로와 쿼리(스프레드·갭·선선갭 화면의 검색어는 지움 — 기록 탭의 코인 칸 sym과 utm_*는 남음), 상태 코드·크기·처리 시간(대시보드 실시간 연결은 연결을 연 시간), 이전 페이지의 사이트 주소(도메인까지), 브라우저·기기 정보(User-Agent). 헤더·쿠키는 남기지 않고, 화면이 몇 초마다 부르는 조회와 감시용 요청은 기록하지 않습니다. www.kimptrack.com은 kimptrack.com으로 옮겨 주기만 하고 기록하지 않습니다. AWS 서울 리전의 서버 파일과 로그 저장소(Amazon CloudWatch Logs)에 둡니다. 운영자가 보는 관리자 화면이 같은 서버에서 이 파일을 읽어 24시간 요약을 만들며, 따로 저장하지 않습니다. 서버의 오류 기록에는 IP를 남기지 않습니다.

화면 이용 기록 — Microsoft Clarity

랜딩과 대시보드에서만 돌고, 유럽 시간대로 설정된 브라우저에서는 돌지 않습니다. 받는 것: 페이지 주소(검색어는 뺌), 클릭·스크롤·마우스 움직임·화면 크기, 화면 내용(입력칸은 늘 가림), 기기·브라우저·운영체제, IP 주소(Microsoft가 받아 대략의 위치를 추정), 쿠키 _clck·_clsk와 sessionStorage _cltk(7절). 받는 곳은 Microsoft Corporation(미국)이며, Microsoft는 이 정보를 Microsoft Advertising 제공 등 자기 목적에도 씁니다(Microsoft 개인정보처리방침에 따름). 한 사람분만 골라 지울 수는 없고 프로젝트를 통째로 지워야 합니다. KimpTrack은 광고 목적 저장에 거부 신호를 보냅니다.

관리자 접속 기록(운영자만)

admin.kimptrack.com 요청마다 시각·로그인 이메일·IP·메서드·경로와 쿼리·상태·처리 시간·Cloudflare 요청 ID·Sec-Fetch-Site를 AWS 서울 리전의 서버 파일에 남깁니다. 로그인은 Cloudflare Access(허용한 이메일로 받는 일회용 코드)가 하며, Cloudflare가 이메일·IP를 처리하고 인증 기록을 24시간 둡니다.

문의 메일

권리 행사·문의로 받은 이메일 주소와 내용을 답변에만 씁니다. 메일 서비스는 Gmail(Google LLC, 미국)입니다.

외부 글꼴 요청

대시보드(/app/)를 열면 방문자의 브라우저가 Google Fonts(Google LLC, 미국)에서 글꼴을 직접 받습니다. 이때 IP·User-Agent·요청 주소·이전 페이지 도메인이 Google로 가고 쿠키는 가지 않으며, Google이 요청 기록을 남깁니다. 운영자만 보는 관리자 화면의 API 문서는 jsDelivr·fastapi.tiangolo.com·Google Fonts에서 화면 파일을 받습니다. 랜딩과 이 페이지는 외부 글꼴을 부르지 않습니다.

처리 근거

KimpTrack은 가입을 받지 않아 동의를 따로 받지 않습니다. 서버·관리자 접속 기록과 화면 이용 기록은 서비스를 제공하고 보안을 지키며 이용 통계를 내기 위한 정당한 이익(개인정보 보호법 제15조 제1항 제6호)으로, 그 목적에 필요한 범위에서만 처리합니다. 화면 이용 기록은 언제든 거부할 수 있습니다. 권리 행사 요청에 답하는 것은 법령상 의무(같은 항 제2호)이고, 그 밖의 문의 답변은 같은 항 제6호에 따릅니다.

3. 개인정보의 파기

보유 기간이 끝나면 끝난 날부터 5일 안에 지웁니다. 서버·관리자 접속 기록은 하루마다 새 파일로 나뉘고, 90일이 지난 파일은 자동으로 파일째 지워집니다. 로그 저장소(CloudWatch Logs)는 보존 기간 90일이 지난 기록을 AWS가 지웁니다. Clarity 기록은 2절의 기간이 지나면 Microsoft가 지웁니다. 문의 메일은 기간이 지나면 운영자가 메일함에서 지웁니다. 법령에 따라 따로 보존하는 기록은 없습니다.

7. 자동으로 수집하는 장치의 설치·운영과 거부

  • 쿠키 _clck — Clarity가 같은 브라우저를 알아보는 무작위 ID, 1년
  • 쿠키 _clsk — Clarity가 한 방문의 페이지를 잇는 값, 1일
  • sessionStorage _cltk — Clarity의 탭 ID, 탭을 닫으면 사라짐
  • localStorage kt.analytics — 이 페이지에서 고른 분석 거부·허용, 서버로 가지 않음
  • 서버 접속 기록 — 2절

거부 방법: 위 “화면 분석 거부” 버튼, 브라우저 설정의 쿠키 차단, 광고 차단기, Microsoft 쪽 쿠키는 DAA 거부 페이지. 거부해도 서비스는 그대로 씁니다.

8. 정보주체의 권리와 행사 방법

누구나 10절의 메일로 자기 개인정보의 열람·정정·삭제·처리정지를 요구할 수 있고, 법정대리인이나 위임받은 사람을 통해서도 할 수 있습니다. KimpTrack은 법이 정한 기간 안에 답합니다. 다만 서버 접속 기록은 IP 끝자리를 지워 남기므로 한 사람의 기록을 가려내기 어렵고, Clarity 기록은 한 사람분만 골라 지울 수 없어 요청이 오면 프로젝트를 통째로 지우는 방법뿐입니다. 화면 분석의 처리정지는 위 버튼으로 바로 할 수 있습니다.

9. 개인정보의 안전성 확보 조치

  • 방문자의 브라우저와 서버 사이는 HTTPS로 암호화합니다.
  • 기록을 줄여 남깁니다 — IP 앞부분만, 검색어·헤더·쿠키는 지움.
  • 관리자 화면은 허용한 이메일의 일회용 코드로 로그인하고, 서버에 들어오는 포트를 열지 않는 터널로만 연결합니다.
  • 서버 접근은 SSH 키와 보안그룹으로 제한합니다.
