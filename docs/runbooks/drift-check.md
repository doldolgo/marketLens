# drift-check.md — 문서↔코드 어긋남 점검

언제: 스펙 3개 완료마다, 또는 실행 세션이 "문서와 다르다"고 보고할 때.

새 세션에 붙여넣기:
```
CLAUDE.md 와 docs/context/*.md 를 읽어라. 그 다음 server/ 와 web/ 의 실제 코드를 보고,
문서가 현실과 다른 지점을 전부 나열하라. 형식: [파일:절] 문서 주장 → 실제.
코드는 고치지 말고, 문서만 고쳐서 커밋하라. 단 어느 쪽이 맞는지 불명확한 항목은 고치지 말고 목록에 "판단 필요" 로 남겨라.
```

원칙: **죽은 내용은 지운다.** "예전엔 ~" 잔재를 남기지 않는다. 역사는 Git commit 에 어차피 남아있다.
