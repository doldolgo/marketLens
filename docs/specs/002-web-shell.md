### 3.3 색 규약·stale·숫자 포맷
- **한국식 색 규약**: 빨강=상승, 파랑=하락. 퍼센트 값의 색 = `>0` 빨강, `<0` 파랑, `0` 은 중립. 모든 김프·갭·펀딩 수치에 적용한다(퍼센트 색 규칙).
- **stale**: 행의 `age`(마지막 수신 후 초) `>= 5` 면 행 전체를 흐리게 그리고 하이라이트 대상에서 제외. `fail` 상태는 표 맨 뒤로 보내고 값은 `–`.
- 포맷 규칙은 전부 순수 함수이며 아래 예시와 정확히 일치해야 한다.
  1. KRW: `≥100` 반올림 정수 ko-KR 콤마. `≥1` 소수 2자리. 그 외 최대 4자리. 예 `12345678`→`12,345,678`, `2.5`→`2.50`, `0.12345`→`0.1235`.
  2. USDT: `≥1000` 콤마+소수 2. `≥1` 소수 3. `≥0.001` 소수 4. 그 외 소수 8. 예 `118420`→`118,420.00`, `2.91`→`2.910`, `0.0000162`→`0.00001620`.
  3. 퍼센트: 양수는 `+` 접두, 소수 2자리, `%`. 예 `1.234`→`+1.23%`, `-0.5`→`-0.50%`, `0`→`0.00%`.
  4. 경과: `<60s` `N초 전`, `<60m` `N분 전`, 그 이상 `N시간 전`(반올림). 예 `3.2`→`3초 전`, `400`→`7분 전`, `7200`→`2시간 전`.
  5. 수량: `≥1000` 정수 콤마. `≥1` 소수 2. 그 외 소수 4. 예 `1234.5`→`1,235`, `0.5`→`0.5000`.
  6. USD: `null`→`–`. 아니면 `$` + 반올림 정수 콤마. 예 `1234567`→`$1,234,567`.
  7. 펀딩: 갭 탭은 소수 3자리 `%`(예 `+0.012%`). 선선갭은 소수 4자리 `%/h`(예 `+0.0015%/h`).
  8. 시각: `M/D HH:mm`(로컬, 월 1-base). 예 `8/23 14:05`.

### 3.4 피드 계약 (003·005 가 의존하는 유일한 인터페이스)
셸은 **공유 피드 객체 하나**를 모든 탭에 내려준다. 피드가 들고 있는 것:
1. `spreads` — 아래 `SpreadRow[]`. 이 스펙에서는 항상 빈 배열.
2. `rate` — USDT/KRW 암묵환율. `0` = 아직 없음.
3. `io` — 키 `"{sym}|{거래소 표시명}"` → `{dep, wd, net}`.
4. mock 탭용 데이터(§3.6~3.10)와 mock 사건 목록 `events(per, now)`(아래).

피드는 **"spreads 행 + rate 를 통째로 교체하는 방법"** 을 하나 제공한다. 교체 시 `io` 는 새 행들로부터 재구성한다(국내·해외 각각 한 항목, `net` 은 `netDom ?? '–'`). 이 스펙에서는 교체를 호출하는 곳이 없다(003 이 1초 폴링으로 호출).
1.5초 tick 마다 모든 행의 `age` 를 1.5 증가시킨다. 폴링이 멈추면 stale 로 드러나게 하기 위해서다.
값의 모양:
- 피드 상태 `FeedStatus` — `ok`·`stale`·`fail` 셋 중 하나.
- 입출금 상태 `IoState` — 열림 / 막힘 / 확인 불가(null) 셋 중 하나. 확인 불가는 초록으로 칠하지 않는다.
- `SpreadRow` — 국내×해외 페어 1개. 003 의 `GET /spreads` 응답 행의 **부분집합**이다 — `rateAsk`·`rateBid` 는 spreads 기능(003)이 확장 타입으로 얹는다. 키:
  - `sym` 코인, `dom` 국내 거래소 표시명, `fx` 해외 거래소 표시명
  - `fwd` 순방향 김프 %, `rev` 역방향 김프 %, `usd` 해외 USD 가격, `spark` 스파크라인용 최근 값 배열
  - `status` 피드 상태, `age` 마지막 수신 후 초
  - `liqDom`·`liqFx` 국내·해외 유동성, `netDom` 국내 입출금 망 이름(없으면 null)
  - `depDom`·`wdDom`·`depFx`·`wdFx` 국내·해외 입금/출금 상태(`IoState`)

`events(per, now)` — 005(기록/통계)가 실 DB 전에 화면을 채우는 mock 사건 목록. 인자: 조회 기간 문자열 `"<N>h"|"<N>d"|"<N>w"`(해석 불가면 24h — 기록 탭은 `7d`·`30d`·`90d` 를 쓴다)·현재 시각 epoch ms. 반환: 사건 배열. 사건 하나는 `{sym, type, dom, start, durMin, peak}` — `type` 은 김프(`kimp`)·역프(`rev`), `dom` 은 국내 거래소 표시명, `start` 는 시작 시각 epoch ms, `durMin` 은 지속 분, `peak` 는 최고 %.
mock 데이터는 전부 문자열 시드 기반 결정론적 난수로 만든다. 리로드해도 같은 모양이어야 하기 때문이다. tick 의 흔들림만 비결정적이어도 된다.

### 3.6 mock 공통
- 코인 24개(순서·기준가 USD): BTC 118420, ETH 4123, XRP 2.91, SOL 182.4, DOGE 0.2134, ADA 0.887, TRX 0.302, LINK 24.6, AVAX 41.2, DOT 8.42, SUI 4.05, APT 10.8, ARB 1.12, OP 2.31, SEI 0.512, ATOM 9.14, NEAR 6.72, HBAR 0.246, ETC 31.5, STX 2.04, ONDO 1.42, PEPE 0.0000162, WLD 3.86, TIA 6.18.
- 해외 거래소 6곳: Binance, Bybit, Bitget, MEXC, Gate.io, Hyperliquid.
- 코인마다 현물 거래소 목록과 선물 거래소 목록을 정한다. (코인 index + 거래소 index) 을 3 으로 나눈 나머지가 1 이 아니면 현물, 2 가 아니면 선물. 단 **Hyperliquid 는 perp 전용**이라 현물 목록에서 뺀다.
- 현물 항목 = `{ex, off, status, age}`. `off` 는 기준가 대비 편차 ±0.15% 내, age 0~8s. 선물 항목 = `{ex, prem, funding, status, age}`. `prem` 은 현물 대비 프리미엄 ±0.7% 내, `funding` 은 ±0.04% 소수 3자리.
- status 는 3% `fail`, 6% `stale`, 나머지 `ok`. stale 항목의 age 는 45~345s.
- tick(1.5초): `fail` 은 그대로. `stale` 항목은 값 고정·age +1.5. 그 외 항목은 25% 확률로 값이 흔들리고(`prem ±0.03`, `off ±0.015`, `funding ±0.002`) age 0 으로, 아니면 age +1.5. 레이더 행도 age +1.5. age 분포(0~8s)와 stale 기준(5s)상 갭 탭 행의 상당수가 상시 반투명인 것은 시연용 의도다.
- 공용 조작 조각 3종: 분절 버튼 그룹, 숫자 입력(라벨 + 입력 + 단위, 기본 `%`, 비숫자 입력은 0), 토글 버튼. 활성·on 상태는 accent 로 강조.

### 3.7 선물–현물 갭 탭
- 행 = 코인 1개. `fail` 아닌 현물×선물 모든 조합의 갭 `((1+prem/100)/(1+off/100) − 1)×100` 중 최대(진입)와 최소(정리)를 채택. 조합이 없으면 fail 행. age = 채택 조합의 현물·선물 age 중 큰 값.
- 컨트롤 바:
  - 심볼 검색(부분 일치, 대소문자 무시). `기준 보기` 분절 `진입 기준`/`정리 기준`. 전환 시 정렬 키도 따라간다. 방향은 진입=내림차순, 정리=오름차순.
  - 숫자 입력 `하이라이트 임계값`(기본 0.5, step 0.1). 토글 `임계 초과만`(진입: 갭 ≥ 임계, 정리: 갭 ≤ −임계).
  - 안내 `양의 갭 = perp > 현물 → 현물 매수 + 선물 숏 · 음의 갭 = 반대 방향`. 우측 `{표시} / {전체} 코인 표시`.
- 표(헤더 sticky). 열 순서: `심볼`, `현물가 USDT`(기준가×(1+off/100)), `진입 갭 · 현물 → 선물`(정리 기준이면 `정리 갭 · …`), `펀딩비`. 갭 열이 가변, 나머지 고정.
- 헤더 클릭 정렬: 같은 열 재클릭 = 방향 반전. 활성 열은 accent + `▾`/`▴`. fail 행·값 없는 행은 항상 뒤.
- 행: 심볼 앞 점, 현물가, `{현물 ex} 현물` 칩 `→` `{선물 ex} 선물` 칩(accent 테두리), 갭은 굵게 + 퍼센트 색. hot 행(fail·stale 아니고 임계 충족) = accent 배경 + 심볼 accent.
- 펀딩 셀 2줄: `+0.0xx%`(퍼센트 색) / `펀딩 N분 후` 또는 `N시간 M분 후`. 주기는 Hyperliquid 1h, Bitget 4h(§3.8 과 동일한 거래소별 주기), 그 외 8h. 현재 시각 기준 남은 시간.

### 3.8 선선갭 탭
- 행 = 코인 1개. `fail` 아닌 선물 거래소 모든 쌍에 대해 두 값을 구한다.
  - 가격갭 `((1+high/100)/(1+low/100) − 1)×100`. high/low 는 prem 높은 쪽/낮은 쪽.
  - 시간당 정규화 펀딩갭 `|fundingA/cycA − fundingB/cycB|`. cyc 는 Hyperliquid 1, Bitget 4, 그 외 8. 거래소마다 펀딩 주기가 달라 시간당으로 맞춰야 비교가 되기 때문이다.
  - 최대 가격갭 쌍과 최대 펀딩갭 쌍을 각각 채택. 최대 펀딩갭 쌍은 `임계 초과만` 토글의 연환산 비교에만 쓰고, 펀딩갭 열의 표시·정렬은 **채택 가격갭 쌍의 펀딩 차**다(§표 참고).
- 컨트롤 바:
  - 검색. 숫자 입력 `가격갭 임계값`(기본 0.3, step 0.1). 숫자 입력 `펀딩갭 임계값 · 연`(기본 20, step 5). 비교는 시간당 펀딩갭×24×365.
  - 토글 `임계 초과만`(가격갭 ≥ 임계 **또는** 연환산 펀딩갭 ≥ 임계).
  - 안내 `perp ↔ perp · 싼 쪽 롱 + 비싼 쪽 숏 · 펀딩비갭은 시간당 정규화`. 우측 표시 건수.
- 표 열 순서: `심볼`, `가격갭`(기본 정렬, 내림차순, 가변 폭), `펀딩갭`.
- 행: 심볼. 가격갭 셀 2줄 = `{low ex}` 칩 `↔` `{high ex}` 칩 + 가격갭(굵게) / `{low ex} 롱 / {high ex} 숏`(보조). 펀딩갭 셀 2줄 = 채택 가격갭 쌍의 펀딩 차 `%/h` / `해당 조합 펀딩갭`.
- hot = 가격갭 ≥ 임계.
