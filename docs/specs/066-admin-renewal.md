## 1. 목적
사람 요청(2026-10-14): ① 모니터링의 모든 그래프에서 **상세(추이)**를 본다 ② **레퍼런스 관리자 대시보드를 조사해 그 디자인으로 리뉴얼**한다 ③ Clarity 분석과 **IP 대역별 상세**를 모니터링 화면에서 본다. 조사 결과는 `docs/admin-design-research.md`(Grafana·Datadog·Vercel·Cloudflare·Stripe·PostHog·Plausible·Linear·shadcn/Tremor·Statuspage — 이 스펙의 근거, 실행 세션은 그 §2~§6 을 읽는다).

## 2. 범위
- 만드는 것: `web/admin/` 전면 개편 — 왼쪽 세로 내비, 토큰(조사 §5 그대로), 페이지 여섯(개요·서버·트래픽·**방문자**·**Clarity**·화면(065 몫 — 링크만)), 전역 기간·비교 선택기, 모든 차트 카드의 **상세 판**, 거르기 칩, 아이콘 SVG 묶음(로컬, `<use href>`), 테스트·가짜 피드 서버 확장.
- 하지 않는 것: 서버 피드(067·068·063·062·038·040 — 읽기만). 공개 사이트. 빌드 도구 없음 그대로. 화면 분석 창(065).
- 바꾸는 기존 것: 064 의 화면 전부(이 스펙이 대신 — 064 §3 은 이 스펙을 가리키는 한 줄로), 064 의 테스트(새 구조로).

## 3. 동작

### 3.1 틀
- **왼쪽 세로 내비**(조사 §3.1): 아이콘+이름 200px, 768~1279px 아이콘만 56px, 768px 미만은 위 줄 ☰ 로 펼치는 시트. 항목: 개요·서버·트래픽·방문자·Clarity·화면. 항목 옆에 그 페이지의 상태 모양(▲ 주의·■ 문제 — 개요 규칙 §3.3 으로 셈). 아래쪽: 마지막 갱신·로그아웃.
- **페이지 머리**: 제목(20px) · 오른쪽에 기간 프리셋 단추 · '비교'(없음·이전 기간·지난주 같은 때, 단축키 X) · '10초마다 · HH:MM:SS'. 고른 값은 주소 `?range=…&cmp=…` 에 둔다(새로고침·링크 유지). 걸어 둔 거르기는 머리 아래 칩 줄(×로 지움), 주소 `&f=<키>:<값>`.
- **토큰**: 조사 §5 의 CSS 변수 그대로(바탕 3단·선·글 3단·강조·상태 4색·차트 8색·진하기 5단·글자·간격·모서리·그림자). **상자 색 고정** collect `--c1` 파랑·data `--c2` 주황·serve `--c3` 청록, 거래소는 `--c1~--c8` 순서. 상태 4색은 상태 표시에만 쓰고 늘 모양(● ▲ ■ ○)+글과 함께. 차트 테마는 CSS 변수에서 읽어 `echarts.registerTheme('kt')`.
- **카드 해부**(조사 §2-2): 머리 = 제목 + 흐린 단위·기간 + 오른쪽 부분 상태 배지 + 상세 단추(⤢) · 몸 = 그림 하나 · 바닥(있을 때) = 비교 한 줄('어제 같은 때보다 ▲ 12%' — 증감에 상태색 없음). 설명은 제목 옆 '?' 툴팁만.
- **차트 규칙**(조사 §2-8·§6): 선 1.5~2px·점은 마우스 올릴 때만·가로 격자 3~4개·눈금 11px·애니메이션 끔·`sampling:'lttb'`. 둘째 y축 대신 같은 시간 축의 위아래 칸(십자선 공유 `axisPointer.link`). 같은 페이지 시간 차트는 `echarts.connect`(상세 판은 빼고). 들어옴/나감·읽기/쓰기는 위·아래로 뒤집은 면적. 기준선(75·85%)은 점선 `markLine`, 경보·끊김 구간은 옅은 `markArea`. 툴팁 글은 모두 `echarts.format.encodeHTML`, `confine:true`.
- **도넛·반원 게이지를 없앤다**: 구성비 = 100% 가로 띠(다섯 조각 + 기타), 순위 = 상위 목록(행 = 이름·값·비율, 글 뒤 값/최댓값 폭의 옅은 막대, 5~8행 + '전체 보기' → 상세 판에서 정렬·찾기·CSV), 게이지는 예산 하나만. 목록 행을 누르면 그 값으로 페이지 전체 거르기(피드가 지원하는 것만 — 지원 안 하면 상세 판만 연다).
- **상태**: 정상은 조용히(옅게), 문제만 진하게. 불러오는 중은 카드 틀과 높이를 먼저 그린 뼈대, 0 은 '0', 값 없음 '–', 실패는 마지막 값을 흐리게 + 머리 '불러오지 못함 · n분 전 값'. 데이터 부르기·만료(401 → 한 번 새로고침)·보이는 동안만 주기는 064 의 공통 모듈 규칙 그대로.

### 3.2 상세 판 (모든 차트 카드 — 조사 §3.3)
- 카드의 ⤢ 또는 카드 제목을 누르면 같은 페이지 위에 거의 전체 화면 판(뒤 가림 `--scrim`, `Esc`·× 로 닫음, 768px 미만은 화면 전체). 주소 `#detail=<카드 id>` — 링크로 열리고 뒤로 가기로 닫힌다.
- 판 안(위→아래): 머리(제목·단위 · 계열 칩(누르면 숨김/보임) · 기간 프리셋(카드보다 길게 — 피드가 주는 가장 긴 창까지) · 비교 · CSV · ×) → 큰 그래프(높이 55vh 안팎, 휠·끌기 확대·이동, 아래 미니맵 슬라이더, 끌어서 구간 골라 확대, '원래대로') → **통계 표**(보이는 구간 기준, 계열마다 한 행: 최소·평균·최대·p95·마지막·이전 기간 대비 차와 %) → **원자료 표**(시각 KST · 계열 값(+이전 값), 최근 순 200행씩 더 보기, 머리 눌러 정렬) → 관련 카드 한 줄(CPU → 크레딧·WS 등).
- CSV: 보이는 구간·보이는 계열 그대로, 시각은 UTC·KST 두 칸, 파일 이름 `kimptrack-<카드 id>-<시작>-<끝>.csv`(브라우저에서 만든 Blob — 서버 호출 없음).
- 비교선: 이전 기간 값을 지금 축에 맞춰(시각 + 기간 길이) 점선·`--text-3`·낮은 z 로. 피드가 이전 기간을 못 주면 비교 단추를 끄고 '이 자료는 비교 없음' title.
  - AWS 시계열: 068 의 `offset=prev`(바로 앞 같은 길이) · 지난주 같은 때는 7일 창에서 잘라 쓴다(24h 이하만).
  - 트래픽 시간별: 24시간 비교는 7d 응답의 `hourly` 에서, 7일 비교는 30d 응답에서 잘라 쓴다. 30일은 비교 없음.
  - Clarity 날별(068 history): 같은 길이의 앞 구간.
- 판을 닫으면 차트 `dispose()`. 판 안 차트는 페이지 `connect` 그룹에 넣지 않는다.

### 3.3 페이지 (조사 §4 배치)
- **개요** — 상태 띠(정상이면 '● 정상 · HH:MM 확인' 한 줄, 아니면 ■ 문제·▲ 주의 칩 — 064 의 규칙 그대로, 칩을 누르면 그 페이지의 그 카드 상세 판), 큰 수 다섯(이전 기간 대비 배지), **거래소 줄**(원천마다 이름·24시간 상태 띠(정상 얇고 옅게·끊김 빨강 칸 전체)·마지막 성공·1시간 성공률), **상자 표**(상자 | CPU·메모리·디스크 문턱 눈금 막대 | 크레딧 | 24시간 CPU 선 — 게이지 아홉 대신), 24시간 트래픽(위아래 세 칸: 사람 모양 페이지·5xx·WS 접속, 십자선 공유).
- **서버** — 064 의 카드 그대로 두 열 배치 + 위 거르기 칩(collect·data·serve = 범례 겸 거르기), 끊김 띠는 custom 계열(정상 얇게·끊김 칸 전체·자료 없음 빗금), 경보는 7일 사건 줄(ALARM 구간 띠·알림 점), 비용은 실제·예측 막대 + 예산선(게이지 하나 유지 가능). 064 의 작은 그림 위 글자 겹침을 없앤다(이름표는 칸 왼쪽 위 한 줄).
- **트래픽** — 큰 수(누르면 아래 큰 추이의 지표가 바뀜 — Plausible), 큰 추이(+이전 기간 점선), 흐름(062 sankey — 드문 길 '기타', 마우스 올리면 앞뒤 고리 강조), 목록 셋(들어온 길·출처 / 나라·망 종류 / 첫·마지막 페이지), 100% 띠 넷(기기·OS·브라우저·요청 종류), 요일×시간 열지도(한 색 진하기), 응답 상태 띠 + 최근 5xx 표, WS 연결 시간 막대.
- **방문자(새)** — IP 대역 표(067): 머리 큰 수 넷(대역 수·데이터센터 대역 요청 비중·상위 10 대역 요청 비중·오늘 처음 본 대역), 거르기(망 종류·나라·봇 포함/뺌·찾기 `1.2.3.`), 표(대역 | 나라·망 | 요청 막대 | 사람 모양 페이지 | 짝 수 | 봇 % | 5xx | 처음~마지막 | 작은 선) — 머리 눌러 정렬·200행씩. 행 → 상세 판(067 `/admin/access/ip`): 시간별 요청 막대·종류 띠·상태 코드 띠·브라우저 정보 목록·경로 상위·첫/마지막 페이지·최근 요청 100줄(시각·경로·상태·종류·브라우저 — 행 펼치기)·[이 대역만 트래픽 보기]·◀ 이전/다음 ▶.
- **Clarity(새)** — 040 피드 + 068 history: 큰 수 여섯(세션·봇 세션·사용자·페이지/세션·평균 스크롤 깊이·활성 시간/전체) + 날별 작은 선, 불만 신호 여섯(신호 있던 세션 % 막대 + 전날 대비), 페이지 × 기기 표(040 `pages.groups`, 칸 진하기), 나라 목록, 기기·브라우저·OS 100% 띠(068 차원), 유입(Channel·Referrer) 목록(068), '맞대기' — Clarity 세션 vs 우리 방문자(038 `visitors.days`) 날별 두 선. 머리에 '마지막 받음 n시간 전 · 다음 HH:MM' 과 'Clarity 열기 ↗'. Clarity 는 IP·개인 단위 자료를 주지 않는다 — 방문자 단위는 '방문자' 페이지(서버 기록)로 안내하는 한 줄.
- **화면** — 065 몫. 이 스펙에서는 내비 항목만(065 가 머지되기 전엔 '준비 중' 빈 페이지 `screens.html` — 내비와 한 줄).

### 3.4 엣지
- 피드가 없거나(404 — 서버 배포 전) 연결 안 됨이면 그 카드만 상태 배지와 빈 그림.
- 주소의 `range`·`cmp`·`f`·`#detail` 이 목록 밖이면 기본값으로, 오류 없이.
- 아주 좁은 화면(360px)에서도 가로 넘침 없음 — 표는 카드 안 가로 스크롤.

## 4. 검증
- node(064 방식 — 가짜 DOM·가짜 echarts 와 진짜 ECharts SVG 그리기): 주소 상태 왕복(range·cmp·f·#detail), 상세 판 통계(최소·평균·최대·p95·마지막·차 — 경계값·null 섞임), CSV 글자(따옴표·쉼표·한국어·UTC/KST), 비교선 시각 이동, 상위 목록 막대 폭, 100% 띠 다섯 + 기타, 거르기 칩, 상태 띠 규칙(064 그대로 통과), IP 대역 표 정렬·찾기, Clarity 날별 선, 툴팁·표 글자 XSS(`<img onerror>` 가 글로만).
- 정적: 페이지 여섯의 내비·현재 표시, 아이콘 묶음 로컬, 인라인 스크립트 없음, CSP 그대로(`style-src 'unsafe-inline'` 만 064 대로), 토큰 이름·상자 색 고정, 도넛·반원 게이지 없음(예산 하나만).
- `cd server && ruff check . && ruff format --check . && pytest -q`, `node --check web/admin/*.js`, `cd web && npm run lint && npm run build`.
- 가짜 피드 서버(`web/scripts/admin-fake-feeds.py`)에 067·068 응답과 경우(대역 많음·대역 없음·XSS)를 더한다.
- 설계 세션(헤드리스 Chrome): 페이지 여섯 1440·1024·390 가로 넘침 0, 상세 판 열기·닫기·뒤로 가기·CSV, 비교선, 거르기, 색각 무늬 토글(있으면), CSP 위반 0.
