## 1. 목적
USDT 시세는 이 시스템의 **유일한 원화↔USDT 변환값**이다(은행 환율 없음 — product.md 용어). 그런데 001 규칙상 관측이 끊기면 직전 값을 **조용히** 유지하므로, KRW-USDT 호가가 오래 안 들어오면 전 종목 김프/역프가 낡은 시세로 계산되는데 화면엔 아무 표시가 없다. 이 스펙은 그 침묵을 없앤다: 시세가 오래 갱신되지 않으면 경고를 만들어 화면의 문구 표시 자리에 띄운다. 함께, 화면에 남은 "환율" 표기를 "USDT 시세"로 정리한다.

## 2. 범위
- 만드는 것: `/spreads` 응답 최상위 `warnings` 배열(staleness 경고), FE 경고 표시 2곳(KPI 블록·스프레드 탭 문구 자리), 공용 문구 표시 조각의 **경고 레벨**(error 외 warning).
- 바꾸는 기존 것: ① 003 `/spreads` — 최상위 키 `warnings` 추가(기존 키 불변, 하위호환). ② 002 셸 — KPI 라벨 `USDT/KRW 암묵환율` → `USDT 시세`, 푸터 문구 교체(아래 §3.5), 빈 상태/에러 문구 표시를 `shared/` 조각으로 승격해 level 지원. 002 의 "shared 수정 금지"는 003 의 규칙이었고, 이 스펙은 명시적으로 shared 를 바꾼다.
- 하지 않는 것: 코드 식별자·API 키 이름 변경(`rate`·`rateAsk`·`rateBid`·`usdkrw` 유지 — FE·BE·문서 전반의 파괴적 변경 대비 이득이 없다, product.md 용어에 다리를 놓았다). 김프 계산 중단이나 행 제외(직전 값 유지 규칙은 그대로 — 경고만 더한다). 수집 루프 변경. `/refresh`·`/history/*` 변경.

## 3. 동작

### 3.1 읽는 계약 (복사)
- 001: USDT 시세는 국내 거래소별 `{exchange, ask, bid, updated_at(aware UTC)}`. 매 사이클 KRW 호가에서 추출하고, 관측 실패 시 직전 값을 유지한다(`updated_at` 이 안 바뀜).
- 003: `GET /spreads` 최상위는 `rate`·`rows`·`data_received_at`·`fetched_at`(snake_case). 행 계산은 각 국내 거래소의 자기 시세를 쓴다.

### 3.2 staleness 판정 (BE, `/spreads` 계산 시)
- 임계 **60초** — 코드 상수. 왜 60초인가: 스냅샷 stale 기준(5초)과 달리 USDT 는 유동성이 높아 매 사이클(1초) 관측되는 게 정상이다. 60초 동안 한 번도 관측이 없으면 일시 결측이 아니라 구조적 문제(KRW-USDT 마켓 중단·응답 형식 변화·수집 회귀)로 본다.
- 국내 거래소마다 `now − rate.updated_at > 60` 이면 최상위 `warnings` 에 1줄:
  `"{거래소id} USDT 시세가 {N}초째 갱신되지 않았습니다 — 이 거래소 행의 김프/역프는 낡은 시세 기준입니다."` (N 은 정수 초)
- 경고가 없으면 `warnings` 는 **빈 배열**(키는 항상 존재). 시세가 아예 없는 거래소는 기존 규칙대로 행이 빠지므로 경고 대상이 아니다 — 경고는 "있긴 한데 낡은" 상태 전용.

### 3.3 FE — 경고 전달·표시
- 폴링(003)이 `warnings` 를 공유 피드에 함께 교체 저장한다. 폴링 실패 시 직전 경고 유지(데이터와 같은 규칙).
- 표시 1 — KPI `USDT 시세` 블록: 경고가 하나라도 있으면 값·라벨을 상태색(주황)으로 칠하고 보조문 `시세 갱신 지연` 을 붙인다.
- 표시 2 — 스프레드 탭의 문구 자리(빈 상태 문구가 뜨는 위치): 표가 정상 표시 중이어도 경고 줄을 **warning 레벨**로 띄운다. 여러 줄이면 전부, 표 위에.

### 3.4 공용 문구 조각 — 경고 레벨
- 002 의 빈 상태/에러 한 줄 문구 표시를 `shared/` 공용 조각으로 만들고 `level ∈ {error, warning}` 을 받는다.
- `error` = 기존 스타일 그대로(내용을 대체하는 문구). `warning` = 상태색(주황, `docs/design/theme.css` 토큰) + **내용과 공존**(표를 가리지 않고 위에 얹힌다).
- 기존 사용처(spreads 빈 상태·필터 0건 등)는 error 레벨로 그대로 동작이 바뀌지 않아야 한다.

### 3.5 화면 문구 정리 ("환율" 제거)
- KPI: `USDT/KRW 암묵환율` → **`USDT 시세`** (값 형식 `₩1,390.0` 은 그대로).
- 푸터: `암묵환율 = 국내 거래소 USDT/KRW 체결가 기준` → **`USDT 시세 = 국내 거래소 KRW-USDT 호가 기준`** (기존 문구는 "체결가" 라 실제 동작(호가 추출)과도 달랐다).
- 그 외 FE 표시 문자열에서 "환율" 을 검색해 남은 것이 없게 한다. 코드 식별자·API 키는 §2 대로 유지.

## 4. 검증
BE (저장소 직접 시드, 네트워크 없음):
- 시세 `updated_at` 이 61초 전인 거래소 → `warnings` 에 그 거래소 1줄, 초 수가 메시지에 있다
- 59초 전 → 빈 배열; 두 거래소 다 61초 전 → 2줄
- `warnings` 키는 경고가 없어도 항상 존재(빈 배열)하고, 기존 최상위 키·행 18키는 불변이다
- 시세가 없는 거래소는 경고에 나타나지 않는다(행 제외 규칙이 이미 처리)
FE:
- 경고 배열이 있으면 KPI `USDT 시세` 가 주황 + `시세 갱신 지연`, 스프레드 탭 상단에 warning 줄이 표와 함께 보인다; 배열이 비면 둘 다 사라진다
- 문구 조각: error 레벨은 기존 빈 상태와 동일 렌더, warning 레벨은 주황이고 표를 대체하지 않는다
- KPI 라벨·푸터가 §3.5 문구다. FE 표시 문자열에 "환율" 이 없다
수동: 서버 기동 → 경고 없음 확인 → 수집을 멈추고(서버는 유지) 60초 뒤 `/spreads` 에 경고 2줄·화면에 주황 표시가 나타난다.
