## 3. 동작
실행 세션이 이 절만 보고 구현한다. 다음만 쓴다:
- **외부 계약**: HTTP 경로·파라미터·응답 JSON 예시·에러(코드·상태·메시지 의미). 화면이면 보여주는 것·조작·색/강조 규칙.
- **규칙·수식**: 계산식, 정렬, 임계값, 주기, 캐시/재시도 정책. 숫자는 값으로.
- **엣지**: 데이터 없음, 부분 실패, 외부 API 장애, 경계값에서 어떻게 되는가.
- **외부 의존**: 거래소 API 라면 엔드포인트·인증 방식·응답에서 쓰는 필드·rate limit·알려진 quirk. (이건 실행 세션이 스스로 알 수 없으므로 구체적으로)
- 다른 스펙이 만든 것을 쓸 때는 그 **계약**(엔드포인트·데이터 모양)을 여기 복사한다.
- **형식**: 표는 2열·셀 한 토큰, 의미는 문장으로. 스키마는 문장으로 쓴다 — 무엇을 저장하는가, 한 행의 유일키, null 의미, 시각 단위, 왜.

쓰지 않는 것: 클래스명·private 함수·변수명·파일 내부 배치. (단, 다른 기능이 import 하는 공유 모듈의 공개 함수 시그니처는 예외)
