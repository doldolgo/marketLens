## 1. 목적
사람 요청(2026-10-16): 관리자 화면을 처음 보는 사람도 각 숫자·그림이 **무엇을 세는지**와 **어떻게 읽는지**를 알게 한다. '?' 를 눌러도 설명이 안 나오고, '누가' 상세 판이 무엇을 말하는지 모르겠고, '화면' 페이지 쓰는 법을 모르겠고, Clarity 가 왜 비어 있는지 모르겠고, '개요' 트래픽의 WS 접속이 사람 모양 페이지보다 작은 이유를 모르겠다는 다섯 가지를 푼다.

## 2. 범위
- 만드는 것: 누를 수 있는 '?' 설명 말풍선, 모든 '?' 의 두 줄 설명(뜻·읽는 법), 상세 판 머리 아래 그 카드의 뜻 한 줄, '누가' 상세 판 개편, '화면' 페이지 쓰는 법 안내, Clarity 페이지 진단 줄, 트래픽 그림의 WS 칸 이름, 테스트.
- 하지 않는 것: 서버·피드 응답(그대로 읽는다). IP 별 화면 재생(사람 결정 대기 — 처리방침·동의 개정이 필요).
- 바꾸는 기존 것: 066 §3.1 '설명은 제목 옆 ? 툴팁만'·064 '? title 한두 문장' 규칙 → 이 스펙 §3.1·§3.2. 066 개요·트래픽의 'WS 접속' 칸 이름.

## 3. 동작

### 3.1 '?' 말풍선
- 모든 페이지의 `?`(카드 머리·큰 수 타일·화면 페이지 판 머리)는 마우스 올림·누름(클릭·터치)·키보드(Tab 으로 가서 Enter·Space)로 말풍선을 연다. 말풍선 하나만 뜬다 — 다른 `?` 를 열면 앞의 것은 닫힌다.
- 닫기: 같은 `?` 를 다시 누름·말풍선 밖 누름·Esc·스크롤·창 크기 바꿈. 마우스 올림으로 연 것은 마우스가 떠나면 닫히고, 누름으로 연 것은 닫을 때까지 남는다. Esc 는 말풍선만 닫는다(열린 상세 판은 그대로).
- 큰 수 타일(트래픽 — 누르면 아래 추이의 지표가 바뀌는 단추) 안의 `?` 를 눌러도 타일은 눌리지 않는다.
- 말풍선 = 두 단락 — 굵은 머리 `뜻` + 첫 줄, `읽는 법` + 둘째 줄. 줄이 하나면 `뜻` 단락만. 화면 밖으로 넘치지 않게 `?` 아래(자리가 없으면 위)에 두고 좌우는 화면 안으로 민다. 최대 폭 340px, 글자는 본문 13px.
- 글은 HTML 의 `title` 에 두고(`&#10;` 로 두 줄), 페이지가 뜰 때 브라우저 기본 툴팁이 겹치지 않게 다른 속성으로 옮긴다. 스크립트가 못 돌면 기본 툴팁이 두 줄로 보인다.
- 접근성: `?` 는 `role=button`·`tabindex=0`·`aria-label="설명"`·`aria-expanded`, 말풍선은 `role=tooltip` 이고 열린 동안 `?` 의 `aria-describedby`.

### 3.2 설명 글 규칙
- 모든 `?` 는 두 줄: **뜻** = 무엇을 세는지(단위·출처·사람 수인지 아닌지), **읽는 법** = 그림 모양·색·선·기준선을 어떻게 보는지와 흔한 오해. 줄마다 120자 이하, 낱말은 화면이 쓰는 이름 그대로(CLAUDE.md 용어).
- 같은 값을 다른 페이지에서 보이면 뜻 줄은 같은 문장이다(예: 개요·서버의 WS 접속).

### 3.3 상세 판의 뜻 줄
- 카드의 ⤢·제목으로 연 상세 판은 머리 아래 안내 줄(`sheet-note`)의 맨 앞에 그 카드 `?` 의 뜻 줄을 둔다. 판 자신의 안내(일부만 읽음 등)가 있으면 그 뒤에 ` — ` 로 잇는다. 카드 `?` 가 없는 판(화면 페이지 판, IP 상세)은 판 자신의 안내만.

### 3.4 '누가' 상세 판
- 판 머리 단위 `기기 · OS · 브라우저 · 요청 종류`. 그림 대신 네 묶음을 위아래로 둔다. 묶음마다: 제목 + 흐린 분모 글(`브라우저 모양 방문자 n명 기준` / 요청 종류는 `모든 요청 n건 기준`) + 한 줄 설명 + 항목 행(이름 · 막대(묶음 안 비율) · 수 · %). 항목은 수 내림차순, 0 은 뺀다.
- 묶음 설명: 기기 = '방문자가 쓴 기기 — 화면 크기가 아니라 브라우저 정보로 가른다', OS = '방문자의 운영체제', 브라우저 = '방문자의 브라우저 — 카카오톡·네이버 같은 앱 안 브라우저는 따로', 요청 종류 = '서버에 온 모든 요청을 보낸 쪽 종류로 — 사람 브라우저 모양만 방문자로 센다'.
- 요청 종류 항목마다 흐린 설명: 사람 브라우저 모양 = '크롬·사파리 같은 브라우저 이름표 — 위장 봇도 섞인다', 검색엔진 = '구글·네이버 같은 검색 로봇', AI 수집기 = 'GPTBot·ClaudeBot 같은 AI 학습·검색 로봇', 링크 미리보기 = '카카오톡·슬랙 등에 링크를 붙였을 때 미리보기를 만드는 요청', 자동화 도구 = 'curl·파이썬·헤드리스 브라우저·감시 도구', 스캐너 = '취약점을 찾는 요청(/.env·/wp-login.php 등)과 이름 없는 봇', 운영자 흔적 = '관리자 화면·로컬 시험에서 온 요청', 이름 없음 = '브라우저 정보가 빈 요청'.
- 아래 표는 그대로(묶음·이름·수·묶음 안 비율, 찾기·정렬·CSV) — 정렬 기본은 묶음 순서(기기·OS·브라우저·요청 종류) 다음 수 내림차순.
- 방문자 값이 없을 때(처리방침 시행 전 등) 기기·브라우저는 사람 모양 페이지로 센다는 066 규칙 그대로 — 그때 분모 글은 `사람 모양 페이지 n건 기준`.

### 3.5 '화면' 페이지 쓰는 법
- 고르기 줄 위에 접는 안내 `이 페이지 쓰는 법`(`<details>`). 페이지를 열 때마다 펼쳐 둔다 — 접은 상태는 기억하지 않는다(관리자 화면은 브라우저 저장소를 쓰지 않는다, 064).
- 내용(목록 다섯): ① 이 페이지는 동의한 방문자가 보낸 화면 이용 통계(우리 서버, Clarity 아님)를 실제 페이지 위에 겹쳐 그린다 — 동의한 사람만이라 수가 작다. ② 위 칩에서 화면(랜딩·대시보드 탭·정적 페이지들)과 기기(PC·휴대폰)를 고른다. ③ 보기 — 요소(단추·링크마다)·영역(덩어리마다)·깊이(어디까지 내려왔나). 지표 — 클릭·마우스 올림(PC)·보인 시간. ④ 진할수록 많다. 빗금은 거의 안 닿은 곳, '표본 적음' 이면 숫자를 믿지 않는다. ⑤ 오른쪽 표의 행을 누르면 그 요소로 화면이 움직이고, ⤢ 로 전체 표·CSV.

### 3.6 Clarity 진단 줄
- Clarity 페이지 머리 아래 한 줄. 화면 이용 통계 피드(052 `days=1`, 오늘 KST)의 페이지 보기 합(`rows[].pv` 합)과 Clarity 요약(최근 24시간 `traffic.sessions`)으로:
  - Clarity 세션 0 이고 통계 페이지 보기 > 0 → 주의 모양 + `Clarity 가 최근 24시간 세션 0 을 돌려줬다. 같은 동의로 도는 화면 이용 통계는 오늘 페이지 보기 n회 — 동의한 방문이 있었는데 Clarity 에 안 잡혔다. Clarity 열기에서 최근 녹화가 있는지, API 토큰이 이 사이트 프로젝트의 것인지 확인한다.`
  - 둘 다 0 → `최근 동의한 방문이 없다(Clarity 세션 0 · 화면 이용 통계 0) — 값이 비는 게 정상이다. 동의한 방문자가 있어야 쌓인다.`
  - Clarity 세션 > 0 → 줄 숨김. 어느 피드든 ok 가 아니면 숨김.

### 3.7 트래픽 그림의 WS 칸
- 개요 트래픽 카드와 트래픽 상세 판의 셋째 칸·계열 이름 `WS 접속` → `대시보드 동시 접속`, 카드 단위 `시간별 · 사람 모양 페이지 · 5xx · 대시보드 동시 접속`.
- 두 값은 단위가 다르다 — 사람 모양 페이지는 **한 시간에 열린 페이지 수**(랜딩·처리방침 포함, 위장 봇 포함), 대시보드 동시 접속은 **그 순간 열려 있는 대시보드 탭 수의 5분 최댓값**(027 게이지 — `/ws/spreads` 연결, 랜딩만 본 방문자는 0). 그래서 동시 접속이 페이지 수보다 작은 것이 정상이다. 이 문장은 트래픽 카드 `?` 의 읽는 법 줄에 쓴다.

## 4. 검증
- node(066 방식 가짜 DOM): `?` 누름 → 말풍선 열림·두 단락(뜻·읽는 법)·`aria-expanded`; 같은 `?` 다시 누름·밖 누름·Esc 로 닫힘; 타일 안 `?` 누름이 타일의 지표를 바꾸지 않음; 한 줄 글은 뜻 단락만; 글자는 글로만(`<img onerror>` 가 요소가 되지 않음).
- 정적: 모든 페이지의 `?` 글은 줄 1~2개·줄마다 120자 이하, 페이지 안 `?` 수가 066 의 카드 수 이상(빠진 카드 없음).
- 상세 판: 카드 `?` 가 있는 판의 안내 줄이 그 뜻 줄로 시작.
- 누가: 묶음 넷의 분모(방문자 / 모든 요청)·막대 폭(묶음 안 비율)·0 항목 빠짐·요청 종류 설명 여덟·방문자 값 없을 때 분모 글.
- Clarity 진단: 세 경우(0·n / 0·0 / n) 와 피드 오류에서 숨김.
- 트래픽 그림 셋째 칸 이름 `대시보드 동시 접속`.
- 브라우저(가짜 피드 `admin-fake-feeds.py`): 여섯 페이지에서 `?` 누름·Esc·휴대폰 폭 390px 에서 말풍선이 화면 안, 화면 페이지 안내 접고 펴기, 콘솔·CSP 오류 0.
