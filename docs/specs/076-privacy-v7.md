## 1. 목적
073 이 동의한 방문자의 **화면 이동 기록**(마우스·손가락 위치, 누른 곳, 스크롤, 보던 영역, 탭 바꿈 — 시각·IP 주소와 함께)을 KimpTrack 서버에 14일 두고, 074 가 운영자에게 IP 별로 다시 보여 준다. 지금 방침·동의 창은 KimpTrack 서버가 '하루 합계로만, 좌표·IP 없이' 모은다고 약속하므로, 모으기 전에 방침을 고치고 동의를 다시 받는다.

## 2. 범위
- 만드는 것: 처리방침 v7(`public/privacy.html`), 이전 판 사본 `public/privacy-20261014-2.html`(v6 — 060·069 사본 꼴), 동의 창 글(`public/clarity.js`)과 방침 동의 상자 글(같은 글자 — test_clarity 대조), 안내 판 올림, 시행일 상수, sitemap, 테스트.
- 하지 않는 것: 동의 칸 구조(세 칸 그대로 — 화면 이동 기록은 수집·이용 칸에 든다), Clarity 쪽 문구, 서버 접속 기록 문단.
- 바꾸는 기존 것: 안내 판 `2026-10-09-2` → `2026-10-16`(clarity.js·attention.js·replay.js·privacy.html 동의 스크립트 네 곳 — 예전 판의 granted 는 '정하지 않음' 이라 동의 창이 다시 묻는다).

### 3.2 새 기록 — 화면 이동 기록(KimpTrack 서버, 동의한 경우만)
방침 2절에 h3 '화면 이동 기록 — KimpTrack 서버' 와 표 한 행(`화면 이동 기록(동의한 경우만)` | `14일`)을 더하고, 아래 사실을 빠짐없이 쓴다.
- 받는 것: 페이지를 연 한 번마다 화면 이름·기기 종류·화면 크기, 마우스·손가락의 위치와 움직임(0.1초 간격까지), 누른 위치와 그곳의 영역 이름, 스크롤 위치(페이지와 영역 안), 가장 크게 보던 영역 이름, 탭을 숨기거나 다시 연 일, 대시보드 탭을 바꾼 일, 그 각각의 시각, 그리고 요청에 따라오는 IP 주소(전체). 그 방문을 가리키는 임의 번호(페이지를 열 때마다 새로 만들고 브라우저에 저장하지 않음).
- 받지 않는 것: 입력한 글자·누른 키·고른 글자·화면에 보이는 글자와 숫자·화면 그림, 쿠키·기기 ID.
- 보내는 때: 페이지를 보는 동안 2초마다, 숨기거나 떠날 때 한 번.
- 쓰임: 운영자가 관리자 화면(관리자 로그인 뒤)에서 IP 주소별로 방문의 움직임을 지금 공개 페이지 위에 다시 보거나(재생), 지금 보는 중인 방문을 몇 초 늦게 따라 보며 화면이 어떻게 쓰이고 어디서 막히는지 알아 고친다. 밖으로 보내지 않는다(Microsoft 포함).
- 보관: AWS 서울 리전의 KimpTrack 서버 저장소(Redis)에 마지막 기록부터 14일, 그 뒤 저장소가 스스로 지운다. 하루 저장량 상한을 넘으면 그날 남은 기록은 받지 않는다.
- 처리 근거: 동의(제15조 제1항 제1호) — 세 가지 모두 동의한 방문자만. 철회하면 그 뒤로 보내지 않는다. IP 주소를 알려 주면 그 IP 의 화면 이동 기록을 지운다(8절).

### 3.3 함께 바꾸는 곳
- 머리 시행일·변경 안내(바뀌는 것 = 위 새 기록, 동의를 다시 묻는다는 것, 이전 판 링크 `/privacy-20261014-2.html`).
- 한눈에 보기의 화면 분석 항목 — KimpTrack 서버가 하루 합계와 함께 동의한 방문의 화면 이동 기록(IP 주소 포함, 14일)도 모은다.
- 동의 상자·동의 창(같은 글): 머리 문장에 '동의한 방문마다 마우스·손가락 위치와 누른 곳·스크롤을 시각·IP 주소와 함께 14일 모아 운영자가 그 방문을 다시 보거나 지금 보는 방문을 따라 보는 데' 를 더하고, 수집·이용 칸의 항목·목적·보유 기간에 화면 이동 기록을 더한다. '저장 규칙' 의 'Clarity와 KimpTrack 영역 통계가 돕니다' 에 화면 이동 기록을 더한다.
- 1절 목적 한 줄, 3절 파기(14일 뒤 저장소가 지움), 7절 행태정보(우리 서버가 동의를 받아 직접 모음), 8절(IP 를 알려 주면 그 IP 의 기록 삭제), 9절 안전성(통계는 좌표가 없고, 화면 이동 기록은 좌표를 받지만 글자·입력값은 받지 않으며 관리자 로그인 뒤에만 열람), '방문자 정보가 가지 않는 곳' 의 Redis 문장(이제 화면 이동 기록도 Redis 에 있다).
- 12절: 시행 문장·이력 첫 항목·대조표(바뀐 문장 전후 — 060·069 꼴).
- 화면 이용 통계 문단의 '마우스 위치는 보내지 않고, IP도 저장하지 않습니다' 는 통계에 대해 참이므로 두되, 바로 뒤에 '화면 이동 기록은 아래' 를 잇는다.

### 3.4 엣지
- 동의 판을 올리므로 지금 동의한 방문자도 다시 묻는다 — 다시 동의하기 전에는 Clarity·통계·화면 이동 기록 셋 다 돌지 않는다.
- 시행일 전 배포(머지가 시행일보다 이르면): 서버가 게이트로 버린다.
