# 074 — admin-replay

상태: DONE | 의존: 073(피드 셋·사건 꼴)·070(방문자 페이지·IP 상세 판)·066(상세 판)·071('?' 두 줄)·065(공개 페이지를 틀로 띄우기·frame-ancestors)

> 이 문서는 이 기능이 **지금 어떻게 동작해야 하는지**를 적는다. 동작이 바뀌면 이 문서를 직접 고치고, 같은 PR 에서 코드·테스트도 맞춘다(CLAUDE.md §4·§6). 사람이 끝까지 읽는 문서다 — 코드를 산문으로 옮기지 않는다.
> 구현 구조(클래스·함수·파일 내부)는 실행 세션의 몫이다. 여기엔 **무엇이 어떻게 동작해야 하는가**만 쓴다.

## 1. 목적
관리자 '방문자' 페이지에서 동의한 방문자의 화면 기록(073)을 IP 마다 찾아 **실제 페이지 위에 커서·누름·스크롤로 다시 보고**, 지금 접속 중인 방문자는 몇 초 늦게 따라 본다.

## 2. 범위
- 만드는 것: 방문자 페이지의 카드 '지금 보는 중'·'화면 기록', IP 상세 판의 '화면 기록' 절, 재생 판(상세 판 `#detail=replay:<sid>`), `replay.js` 의 재생 쪽(틀 안), 가짜 피드 응답, 테스트.
- 하지 않는 것: 새 관리자 페이지(방문자 페이지 안에서 한다). 그때의 화면 내용 — 틀은 **지금** 공개 페이지를 띄우고 움직임만 그때 것이다(화면 글자는 모으지 않는다, 073).
- 바꾸는 기존 것: 070 IP 상세 판에 절 하나, `clarity.js` 는 `kt-replay=1` 틀에서도 동의 창·태그를 띄우지 않는다(053 의 `kt-overlay=1` 과 같게).

## 3. 동작

### 3.1 방문자 페이지 카드 둘
- **지금 보는 중**(073 `live`, 5초마다 — 페이지가 보일 때만): 행 = IP · 지금 화면 · 기기 · 머문 시간(`last − first`) · 마지막 움직임 'n초 전'. 행을 누르면 재생 판이 **따라 보기**로 열린다. 없으면 '지금 기록 중인 방문 없음 — 동의한 방문자만 기록된다'.
- **화면 기록**(073 `sessions`, 느린 묶음 60초): 최근 조각 표(시작 KST · IP · 화면(지나간 화면들) · 기기 · 길이 · 누름 수), 머리 눌러 정렬·찾기(IP·화면). 행 → 재생 판.
- 두 카드 `?` 는 071 두 줄. 뜻 줄에 '동의한 방문자만, 14일 보관'.

### 3.2 IP 상세 판의 '화면 기록' 절
- 070 판의 '어디' 아래에 절 하나: 그 IP 의 조각(073 `sessions?ip=`) 표(시작·화면·기기·길이·누름) — 행 [재생]. 조각이 없으면 '이 IP 의 화면 기록 없음 — 동의한 방문만 기록된다'. 가린 대역 행(전체 저장 전)에는 절을 두지 않는다.

### 3.3 재생 판 (`#detail=replay:<sid>`)
- 머리: `화면 재생` · 단위 `IP · 기기 · 시작 KST`. 판 몸 = 왼쪽 **틀**(크게) + 오른쪽 **사건 목록**(좁은 화면에서는 아래).
- 틀: `https://kimptrack.com` 의 그 화면 주소 + `kt-replay=1`(대시보드는 `/app/?tab=<탭>&kt-replay=1`). 틀 크기 = 조각의 화면 크기(w×h, `r` 사건이면 그 값), 칸에 맞춰 줄인다(065 의 `--fit`·`--stage-h` 꼴, 늘리지 않음). 틀이 5초 안에 준비를 알리지 않으면 '페이지를 띄우지 못했다(공개 사이트가 관리자 출처를 허용하는지)' 한 줄.
- 조절 줄: ▶/❚❚ · 속도 `1× 2× 4× 8×` · `빈 시간 건너뛰기`(기본 켬 — 사건 사이 5초 넘는 틈을 1초로) · 시간 막대(누름 = 빨간 점, 화면 바뀜 = 세로 눈금, 숨김 구간 = 회색 칸, 끌거나 눌러 옮김) · 글 `HH:MM:SS KST · 경과 m:ss / 전체 m:ss`. Space = 재생/멈춤, ←/→ = 5초.
- 재생: 사건 시각 = 묶음 `at`(서버 받은 시각) − 그 묶음 마지막 `t` + 사건 `t` 로 서버 시계에 맞춘다(묶음 사이 시계 어긋남을 없앤다). 조각 묶음은 073 `session` 을 `next` 로 끝까지 받는다.
- 사건 목록: 시각 · 종류 이름(움직임은 빼고 — 누름·스크롤 크게·화면 바뀜·숨김/보임·보던 영역) · 영역 이름(071 이름표, 모르면 id). 행 누르면 그 시각으로.
- **따라 보기**(지금 보는 중에서 연 판): 2초마다 `session?after=next` 로 새 묶음을 받아 1× 로, 마지막 사건에서 3초 뒤를 따라간다. 머리에 '● 따라 보는 중 · n초 늦음'. 30초 동안 새 묶음이 없으면 '방문자가 떠났거나 멈춤' 으로 바꾸고 받기를 멈춘다. 시간 막대를 뒤로 끌면 따라 보기를 끄고 재생으로.

### 3.4 틀 안 (`replay.js` 재생 쪽 — 틀 안이고 `kt-replay=1` 일 때만)
- 기록(073)은 하지 않는다. 누름·입력·링크 이동·폼은 막는다(053 덮어 보기와 같이). 휠·터치 스크롤도 막는다(관리자가 움직이지 않게 — 화면은 재생이 정한다).
- 준비 알림: 문서를 읽고 나서 관리자 출처(`https://admin.kimptrack.com`)로 `{type:"kt-replay-ready", v:1, page}` 를 보낸다(대시보드는 React 가 그린 뒤 — `data-area` 가 생긴 뒤 한 번 더).
- 관리자 출처의 메시지만 받는다 — `{type:"kt-replay", v:1, x, y, touch, click, sy, els, area}`: `sy` 로 문서 스크롤(null 이면 그대로), `els` = `[[영역, n, top]…]` 로 영역 안 스크롤(073 §3.2 의 n 규칙으로 요소 찾기), `x`·`y` 에 커서(null 이면 숨김 — `touch` 가 참이면 반투명 원, 아니면 흰 테두리 검은 화살표), `click` 이 참이면 그 자리에 0.6초 퍼지는 원, `area` 영역(id, 없으면 `""`)에 옅은 테두리. 값은 꼴을 검사한 수·id 만 쓰고 글자는 textContent 로. 관리자는 재생 시각이 바뀔 때마다 그 시각의 상태(마지막 위치·스크롤·영역)를 한 메시지로 보낸다 — 틀은 받은 상태만 그린다(사건을 모으지 않는다).

### 3.5 엣지
- 조각이 만료(14일)·없음 → 판 한 줄 '기록이 없거나 지났다(14일 보관)'. 묶음 1MB 상한으로 끝이 잘린 조각은 머리에 '앞부분만' 배지.
- 조각 중간 대시보드 탭 바뀜(`p`) → 틀 주소를 그 탭으로 바꾸고 준비를 기다린 뒤 그 시각부터 이어 간다.
- 문서 높이가 지금과 달라 `sy` 가 끝을 넘으면 끝까지만(브라우저 기본).

  `replaysheet.js`(판 `replay` — 쪽 넘기기·재생·따라 보기·키보드) · `replaycards.js`(카드 둘·IP 판 절). 고친 것: `common.js`(PATHS 셋·`LIVE_MS` 5초·

  `addrdetail.js`(절·sessions?ip 부르기), `visitors.html`·`visitors.js`, `admin.css`, 가짜 피드(`admin-fake-feeds.py` — 셋 + 경우), 시험.
- 틀로 보내는 메시지: 재생 시각이 바뀔 때마다(재생 중 50ms 간격, 같은 상태는 다시 안 보냄) `{type:"kt-replay", v:1, x, y, touch, click, sy, els, area}` 를
  `https://kimptrack.com` 으로, `kt-replay-ready`(출처·창·지금 띄운 화면·꼴)를 받은 틀에만.
- 추측한 지점(스펙에 없어 정함): ① 피드 행에 `w`·`h` 가 없으면 첫 `r` 사건, 그것도 없으면 기기 기본값(PC 1280×800 · 휴대폰 390×844) — 073 행에
  `w`·`h` 가 있으면 쓴다. ② `click` 은 재생으로 지난 구간 안의 누름에만 한 번 참(되감기·건너뛰기는 거짓), 그 메시지의 `x`·`y` 는 누른 자리.
  ③ 커서는 숨김 구간·첫 포인터 전에는 null, 손가락 기기(`dev` mobile)는 마지막 움직임 뒤 1초까지만. ④ `sy` 는 마지막 `s`, 없으면 0(막 연 페이지 —
  null 은 쓰지 않는다). ⑤ 영역 안 스크롤·보던 영역은 지금 화면 조각(`p` 사이) 안에서만 — 조각에서 본 (영역, n) 은 첫 사건 전 0, 영역 id 꼴만 보낸다.
  ⑥ 사건 목록 '스크롤 크게' = 1초 안 이어진 한 번 굴림이 300px 이상(문서·영역 안 따로), `r` 은 목록에 넣지 않음, 1,500줄 상한. ⑦ 따라 보기를 끄는 것 —
  뒤로 끌기(스펙)에 더해 멈춤·속도 바꿈. 끝에 닿으면 마지막 사건에서 멈춘다. 새 묶음 뒤 마지막 사건 − 3초보다 8초 넘게 뒤처졌으면(처음·숨었다
  돌아옴) 그리로 건너뛴다. 'n초 늦음' = 마지막 묶음 `at` + 받은 뒤 흐른 시간 − 재생 시각. ⑧ '앞부분만' — 피드(073 행)의 `cut` 이 참이면 그것, 아니면 묶음
  3,600개 또는 `bytes` ≥ 1MB − 16KB 로 어림. ⑨ 관리자 문서가 숨으면 틀을 about:blank 로(대시보드 실시간 연결 — 065 와 같음)·재생·받기를 멈추고,
  보이면 다시 띄워 준비까지 시계를 멈춘다. 판을 닫아도 about:blank. ⑩ 다 받으면 곧바로 재생(1×·건너뛰기 켬), 끝에서 ▶ 면 처음부터.

  기록되고 14일 보관한다'. ⑫ 좁은 화면 기준은 1279px 아래(사건 목록이 아래로).
