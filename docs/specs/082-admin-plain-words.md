# 082 — admin-plain-words

상태: DONE | 의존: 038(줄 분류 — 종류 여덟·페이지 줄)·067(대역 상세 `recent`)·069(IP 상세 `recent`·`flags`·판정 근거 글)·070(IP 상세 판)·071('?' 말풍선 두 줄)

> 이 문서는 이 기능이 **지금 어떻게 동작해야 하는지**를 적는다. 동작이 바뀌면 이 문서를 직접 고치고, 같은 PR 에서 코드·테스트도 맞춘다(CLAUDE.md §4·§6). 사람이 끝까지 읽는 문서다 — 코드를 산문으로 옮기지 않는다.
> 구현 구조(클래스·함수·파일 내부)는 실행 세션의 몫이다. 여기엔 **무엇이 어떻게 동작해야 하는가**만 쓴다.

## 1. 목적
사람 요청(2026-10-18): 관리자 방문자 페이지 IP 상세 판의 '최근 요청' 에서 종류 칸 글('사람 브라우저 모양'·'운영자 흔적' 등)과 '사람 모양 페이지' 가 무슨 뜻인지 처음 보는 사람이 알 수 없다. 이름표를 쉬운 말로 바꾸고, 경로마다 주소를 직접 열어 들어간 페이지인지 어떤 페이지를 열 때 함께 따라온 파일인지 표시한다.

## 2. 범위
- 만드는 것: 관리자 화면 이름표(요청 종류 여덟과 설명·페이지 수·방문자 상한), 최근 요청 표의 '페이지·파일' 칸(배지)과 칸 머리 '?' 말풍선, 표 칸 머리 '?' 를 다는 방법, 판정 근거 글 둘, 가짜 피드 최근 요청 줄, 시험.
- 하지 않는 것: API 응답의 키와 값(종류 키 `browser`… 여덟·`humanPages`·`shaped`·`pages` 그대로 — 서버는 판정 근거 글 둘만 바꾼다), 038 의 줄 분류 규칙, 처리방침, 방문자 페이지의 화면 기록 카드(074).
- 바꾸는 기존 것: 071 §3.4 요청 종류 설명·분모 글·§3.7 카드 단위, 070 §3.3 최근 요청 칸, 069 §3.4 근거 글 둘(뜻은 같다), 038 §3.4 종류 이름 괄호, 064·066 의 '사람 모양 페이지'·'브라우저 모양' 칸 이름.

## 3. 동작

### 3.1 이름표
- 요청 종류(038 §3.4 의 키 → 화면 이름) — '누가' 판·IP/대역 판 '요청 종류' 띠·최근 요청 '종류' 칸이 같은 이름을 쓴다:
  `browser` 일반 브라우저 · `search` 검색 로봇 · `ai` AI 로봇 · `preview` 링크 미리보기 · `tool` 자동화 도구 · `scanner` 그 밖 봇·스캐너 · `operator` 운영자 접속 · `unknown` 브라우저 정보 없음. 표에 없는 키는 원래 글자 그대로(066).
- '누가' 판 요청 종류 항목의 흐린 설명(071 §3.4):
  - 일반 브라우저 = '크롬·사파리 같은 보통 브라우저로 온 요청 — 사람이 대부분이지만 브라우저인 척하는 봇도 섞인다'
  - 검색 로봇 = '구글·네이버 같은 검색엔진이 페이지를 읽어 가는 로봇'
  - AI 로봇 = 'GPTBot·ClaudeBot 같은 AI 학습·검색 로봇'
  - 링크 미리보기 = '카카오톡·슬랙 등에 링크를 붙였을 때 미리보기를 만드는 요청'
  - 자동화 도구 = 'curl·파이썬·헤드리스 브라우저·감시 도구 같은 프로그램'
  - 그 밖 봇·스캐너 = '취약점을 찾는 요청(/.env·/wp-login.php 등)과 위 목록에 없는 봇'
  - 운영자 접속 = '운영자가 관리자 화면·Clarity·로컬 시험에서 띄운 요청 — 방문자로 세지 않는다'
  - 브라우저 정보 없음 = '자기가 무엇인지(브라우저 정보)를 비워 보낸 요청'
  - 묶음 설명 = '서버에 온 모든 요청을 보낸 쪽의 종류 — 일반 브라우저만 방문자로 센다.'
- 페이지 수 — 038 `humanPages`·067/069 `pages`·시간별 `pages`(일반 브라우저의 페이지 줄 수)는 **브라우저로 연 페이지**: 카드 칸·계열·표 칸 이름, 분모 글 `브라우저로 연 페이지 n건 기준`.
- 방문자 상한 — 038 `shaped` 는 **브라우저로 온 방문자**(분모 글 `브라우저로 온 방문자 n명 기준`), 표 칸·흐름 그림 말풍선처럼 좁은 자리는 **브라우저로 온**, 큰 수 타일 단위는 좁아서 `확인 ~ 최대`(확인 = 하한, 최대 = 브라우저로 온 수 — 타일 '?' 의 뜻 줄이 둘을 이 이름으로 풀어 쓴다). '확인된 방문자'·'스크립트가 돈 페이지'·'JS 신호' 는 그대로.
- 판정 '운영자' 의 점수 줄은 `점수 – → 운영자(운영자 접속 — 점수 안 셈)`.
- 판정 근거 글(069 §3.4 — 서버가 만든다): `ua_tool` = `자동화 도구·봇·스캐너 요청 n번`, `ua_many` = `서로 다른 브라우저 정보 n개`. 나머지 글·가중치·차례는 그대로.
- 관리자 화면(web/admin 의 스크립트·HTML) 어디에도 '사람 모양'·'브라우저 모양'·'사람 브라우저'·'운영자 흔적' 글자가 보이지 않는다. 서버 스펙·코드 안의 개념 이름(038 의 '운영자 흔적'·'페이지 줄')은 그대로 두고, 화면 이름표만 이 절을 따른다.

### 3.2 최근 요청의 '페이지·파일' 칸
- IP 상세 판(070)·대역 상세 판(067)의 최근 요청 100줄 표에 '경로' 다음 칸 '페이지·파일' — 줄마다 배지 하나. 서버 응답은 그대로 쓴다(`recent` 의 `path`·`kind`·`referer` — `referer` 는 027 이 남긴 출처 origin 만).
- 가르기 — 위에서 먼저 맞은 것:
  1. **직접 연 페이지** — 경로의 마지막 조각(마지막 `/` 뒤)에 점이 없고 `/api/` 로 시작하지 않는다(`/`·`/app/`·`/privacy`). 주소창에 치거나 링크·검색 결과를 눌러 연 페이지다. 038 페이지 줄과 같은 모양이지만 메서드·상태는 보지 않는다 — 404 난 `/admin` 탐색도 그 주소를 직접 부른 것이다.
  2. **함께 받은 파일** — 출처(`referer`)가 있다. 어떤 페이지가 열리며 저절로 받은 스크립트·스타일·그림·글꼴·API 다. 우리 페이지는 Referrer-Policy `strict-origin` 이라 출처는 `https://kimptrack.com`.
  3. **함께 받은 파일** — 종류가 `browser` 이고 경로가 실시간 연결(`/api/ws/` 로 시작)이나 탭 아이콘(`/favicon.`·`/apple-touch-icon` 으로 시작, `/icon-192.png`)이다. 브라우저는 이 둘에 출처를 싣지 않는다 — WebSocket 은 표준이 출처를 빼고, 탭 아이콘은 브라우저가 페이지와 따로 받는다.
  4. **따로 부른 파일** — 나머지. 페이지 없이 그 파일·주소만 부른 요청이다 — robots.txt·sitemap.xml 을 읽는 검색 로봇, `/.env`·`/wp-login.php` 를 찾는 스캐너, curl 이 흔하다.
- 경로가 `/` 로 시작하지 않으면(빈 값 포함) 배지 없이 '–'.
- 배지 모양: 직접 연 페이지 = 강조색 옅은 바탕, 함께 받은 파일 = 회색 바탕·흐린 글자, 따로 부른 파일 = 바탕 없이 점선 테두리. 상태색(빨강·주황)은 쓰지 않는다 — 좋고 나쁨이 아니다. 정렬·찾기·CSV 는 배지 글자로.
- '페이지·파일' 칸 머리 '?'(071 두 줄):
  - 뜻: `직접 연 페이지 = 주소창에 치거나 링크를 눌러 연 페이지. 함께 받은 파일 = 그 페이지가 열리며 저절로 받은 스크립트·그림·글꼴·API·실시간 연결.`
  - 읽는 법: `따로 부른 파일 = 페이지 없이 파일만 부른 요청 — robots.txt 를 읽는 검색 로봇, .env·.php 를 찾는 스캐너가 흔하다. 경로와 출처(행을 누르면 보인다)로 가른다.`
- '종류' 칸 머리 '?':
  - 뜻: `이 요청을 보낸 쪽 — 브라우저 정보(UA)로 가른다. 일반 브라우저·검색 로봇·AI 로봇·링크 미리보기·자동화 도구·그 밖 봇·스캐너·운영자 접속·브라우저 정보 없음.`
  - 읽는 법: `일반 브라우저에도 브라우저인 척하는 봇이 섞인다 — 판정 근거와 같이 본다. 운영자 접속은 관리자 화면·Clarity·로컬 시험에서 띄운 요청이다.`

### 3.3 표 칸 머리 '?'
- 관리자 표(066 의 표 — 카드 표·상세 판 표)의 칸은 설명 글을 가질 수 있다. 글이 있으면 칸 이름 뒤에 071 의 '?'(같은 아이콘·말풍선·키보드 규칙)를 붙인다.
- 칸 머리 '?' 를 눌러도 정렬은 바뀌지 않는다(071 의 타일 안 '?' 와 같은 규칙). CSV 머리 줄은 칸 이름만.

## 4. 검증
- node(066 방식 가짜 DOM):
  - 이름표: 종류 키 여덟은 그대로·이름 여덟과 설명 여덟이 §3.1, 표 밖 키는 원래 글자; '누가' 분모 글 `브라우저로 온 방문자 n명 기준`·방문자 값이 없을 때 `브라우저로 연 페이지 n건 기준`; 운영자 점수 줄.
  - 가르기: `/`·`/app/`·`/privacy`·404 난 `/admin` → 직접 연 페이지 / 출처 있는 `/app/assets/x.js`·`/api/history/candles` → 함께 받은 파일 / 출처 없는 `/api/ws/spreads` 는 `browser` 면 함께 받은 파일·`tool` 이면 따로 부른 파일 / 출처 없는 `/favicon.svg`(`browser`) → 함께 받은 파일 / 출처 없는 `/robots.txt`(`search`)·`/.env`(`scanner`) → 따로 부른 파일 / 빈 경로·`/` 로 시작하지 않는 경로 → '–'.
  - IP 판: 표 머리 `시각(KST) · 경로 · 페이지·파일 · 상태 · 종류 · 브라우저 · 신호`, 배지 글과 모양 클래스, 칸 머리 '?' 둘(두 줄 글)·'?' 눌러도 정렬 그대로, CSV 머리와 줄에 '페이지·파일' 글자. 대역 판도 같은 칸.
- 정적: web/admin 의 스크립트(주석 빼고)·HTML 에 '사람 모양'·'브라우저 모양'·'사람 브라우저'·'운영자 흔적' 이 없다. 칸 머리 '?' 글은 071 규칙(두 줄·줄마다 120자 이하).
- 서버: 근거 글 둘(`ua_tool`·`ua_many`).
- 브라우저(가짜 피드 `uv run web/scripts/admin-fake-feeds.py --port 18074 --scenario ok` — 포트는 비어 있는 것): 방문자 페이지 IP 표 → IP 상세 판의 최근 요청 배지 셋·칸 머리 말풍선, 트래픽 '누가' 판·개요 트래픽 카드의 새 이름, 콘솔 오류 0.
