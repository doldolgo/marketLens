# 075 — privacy-v9-ga

상태: DONE | 의존: 078(처리방침 v8 — 바로 앞 판, 안내 판 `2026-10-16-2`, 서버 상수 `PRIVACY_V8_EFFECTIVE`)·076(처리방침 v7)·060(같은 날 두 번째 판·이전 판 사본 꼴·'시행일 = PR 올린 날')·033(동의 창·Clarity 불러오기·켜기 = ID 가 든 PR 머지)·052·073(동의 판정·안내 판 값 네 곳)

> 이 문서는 이 기능이 **지금 어떻게 동작해야 하는지**를 적는다. 동작이 바뀌면 이 문서를 직접 고치고, 같은 PR 에서 코드·테스트도 맞춘다(CLAUDE.md §4·§6). 사람이 끝까지 읽는 문서다 — 코드를 산문으로 옮기지 않는다.
> 구현 구조(클래스·함수·파일 내부)는 실행 세션의 몫이다. 여기엔 **무엇이 어떻게 동작해야 하는가**만 쓴다.

## 1. 목적
랜딩과 대시보드의 방문 통계(어디서 왔는지·어느 페이지를 봤는지·얼마나 머물렀는지)를 Google Analytics 4 로 본다. Clarity 와 **같은 동의**(세 칸)를 받은 방문자에게만 태그를 불러오고, 받는 곳에 Google 이 늘어나므로 처리방침을 v9 로 고치고 동의를 다시 받는다.

## 2. 범위
- 만드는 것: GA 불러오기(`public/clarity.js` 안 — 동의 판정·동의 창이 이미 여기 있다), 처리방침 v9(`public/privacy.html`), 이전 판 사본 `public/privacy-20261016-2.html`(v8 — 060·076·078 사본 꼴. v7 사본 `privacy-20261016.html` 은 078 이 이미 만들었다), 동의 창 글과 방침 동의 상자 글(같은 글자 — test_clarity 대조), 안내 판 올림, sitemap, 테스트, 런북 `docs/runbooks/google-analytics.md`.
- 하지 않는 것: 동의 칸 구조(세 칸 그대로 — Google 은 제공·이전 칸의 받는 자에 더한다), Google Ads 연결·전환 추적, 직접 만든 이벤트(탭 바꿈·버튼 클릭 등 — 첫 판은 GA 기본 수집만), 관리자 화면에 GA 숫자 보이기, Google 태그 관리자(GTM).
- 바꾸는 기존 것: 안내 판 `2026-10-16-2` → v9 판 값(3.7 — clarity.js·attention.js·replay.js·privacy.html 동의 스크립트 네 곳 — 예전 판의 granted 는 '정하지 않음' 이라 동의 창이 다시 묻는다). clarity.js 의 '부르지 않는 문서는 예전 저장값을 지운다' 에 GA 쿠키를 더한다.

## 3. 동작

### 3.1 설정과 켜기
- clarity.js 머리에 값 하나를 더한다: GA 측정 ID(`G-` 로 시작하는 공개 값). 빈 문자열이면 GA 는 아무것도 하지 않는다 — 끄기는 이 값을 비우는 PR 이다.
- 켤 페이지·호스트·덮어 보기 제외(053)는 Clarity 와 같다(`PAGES`·`kimptrack.com` 하나·`kt-overlay=1` 틀 안 제외).
- 동의 창은 Clarity ID 와 GA ID 가운데 **하나라도** 있으면 뜬다. 지금은 Clarity ID 가 비면 파일 전체가 아무것도 하지 않는데, 이 조건을 '둘 다 비면' 으로 바꾼다.
- **켜기 = ID 가 든 v9 PR 머지**(033 꼴). ID 가 아직 없으면 PR 을 열어 두고 머지하지 않는다 — PR 본문에 적는다. 머지 = 게시이므로 **법률 확인(사람)을 마친 뒤 머지한다**.

### 3.2 불러오기 — 동의한 방문자만
- 판정은 Clarity 와 하나다: 지금 판의 granted 인 방문자만. GPC·저장소 예외·거부·정하지 않음·`www` 에서는 Google 요청이 0건이다. **동의 전에는 Google 스크립트도 불러오지 않는다**(Consent Mode 의 '거부 상태 핑'도 보내지 않는다).
- 부르는 때도 Clarity 와 같다: 파일이 돌 때 이미 켜는 값이면 DOMContentLoaded 뒤, 동의 창 저장·다른 탭의 동의로 켤 때는 곧바로. 한 문서에서 두 번 부르지 않는다.
- 부를 때 넣는 값:
  - 동의 신호(첫 호출, 태그보다 먼저): 광고 저장·광고용 사용자 데이터·광고 개인화 **거부**, 분석 저장 **허용**.
  - Google 신호 데이터 끔, 광고 개인화 신호 끔.
  - 페이지 주소는 검색어(`?` 뒤)와 `#` 뒤를 뺀 주소로 보낸다 — Clarity 의 '검색어는 뺌' 과 같은 약속. 이전 페이지 주소는 브라우저가 주는 그대로다.
  - 쿠키 보관: 마지막 방문부터 **2개월**(GA 기록 보관 3.4 와 같게 — 기본값 2년을 줄인다).
- 불러오는 주소는 `www.googletagmanager.com`(태그)이고, 보내는 곳은 `*.google-analytics.com` 이다. 공개 페이지의 CSP 는 `frame-ancestors` 만 두므로 막지 않는다.

### 3.3 거부·철회
- [모두 거부]·[동의 철회]·판이 바뀌어 다시 묻는 동안: GA 를 부르지 않고, 남은 GA 쿠키 `_ga`·`_ga_<스트림 기호>` 를 Clarity 쿠키와 같은 꼴(도메인 속성 없이 한 번, `kimptrack.com` 으로 한 번)로 지운다 — clarity.js 의 '부르지 않는 문서' 와 privacy.html 동의 스크립트의 철회 쪽 두 곳.
- 이미 Google 로 보낸 기록은 지울 수 없고 3.4 의 기간 동안 남는다. 지우기를 원하면 메일로 요청 → 운영자가 GA 의 데이터 삭제 요청으로 그 기간의 기록을 지운다(지우는 시점은 Google 기준 — 런북).

### 3.4 GA 속성 설정 — 방침에 쓰는 값(사람이 GA 관리 화면에서)
방침이 이 설정을 사실로 적으므로 런북대로 맞추고, 바꾸면 방침도 고친다.
- 데이터 보관(이벤트·사용자 단위): **2개월**. 사람을 가리키지 않는 합계 보고서는 GA 가 기간 없이 둔다.
- Google 신호 데이터: 끔. 광고 개인화: 모든 지역 끔.
- 계정 데이터 공유 설정(Google 제품·서비스, 모델링 기여, 기술 지원, 전문가 상담): 모두 끔.
- 향상된 측정: 페이지 조회·스크롤·나가는 링크 클릭만 켬. 페이지 조회의 '브라우저 기록 이벤트 기반 페이지 변경' 끔 — 대시보드가 주소에 쓰는 쿼리(기록 탭의 `sym` 등)가 검색어를 뺀 `page_location` 을 거치지 않고 Google 로 가지 않게. 양식 상호작용·사이트 검색·동영상·파일 다운로드 끔 — 입력한 글자를 받지 않는다는 약속과 맞춘다.
- IP: GA4 는 IP 로 나라·도시를 추정한 뒤 IP 자체는 기록·저장하지 않는다(Google 설명). 세분화된 위치·기기 데이터 수집은 기본(켬)으로 둔다.

### 3.5 방침 v9 — 새로 쓰는 사실
방침 2절에 h3 '방문 통계 — Google Analytics' 를 더하고 아래 사실을 빠짐없이 쓴다.
- 받는 것: 페이지 주소(검색어 뺌)·페이지 제목·이전 페이지 주소, 페이지 조회·스크롤(90%까지 내림)·나가는 링크 클릭·머문 시간, 기기 종류·브라우저·운영체제·화면 크기·언어, IP 주소(Google 이 대략의 나라·도시를 추정하고 IP 는 저장하지 않음), 쿠키 `_ga`·`_ga_<스트림 기호>` 의 임의 번호.
- 받지 않는 것: 입력한 글자·마우스 위치·화면 내용, 이름·연락처.
- 받는 곳: Google LLC(미국). 쓰임: KimpTrack 이 방문 통계를 보는 데. Google 은 서비스를 제공·유지·보호하는 데 쓰며, 데이터 공유 설정·Google 신호·광고 개인화를 모두 꺼 Google 의 광고·제품 개선에는 넘기지 않는다. **(법률 확인 대상 — 3.7)**
- 보관: Google 에 2개월(합계 보고서는 기간 없음), 브라우저 쿠키는 마지막 방문부터 2개월.
- 처리 근거: 동의(제15조 제1항 제1호·제17조 제1항 제1호·제28조의8 제1항 제1호) — Clarity 와 같은 세 칸에 모두 동의한 방문자만.

### 3.7 시행일·판·법률 확인
- 시행일 = PR 올린 날 KST(060 꼴 — 다른 날 머지하면 `<time>` 넷·머리·sitemap·판 값·test_privacy 를 그날로). 안내 판 값 = 시행일. v8 과 같은 날(2026-10-16)이면 `2026-10-16-3`(060 의 같은 날 두 번째 판 꼴을 이어서), 이전 판 사본 이름도 그 꼴(v8 = `privacy-20261016-2.html`).
- 서버 게이트는 없다 — Google 로 가는 것은 방문자의 브라우저이고, 판이 바뀌면 다시 동의하기 전까지 아무것도 부르지 않기 때문이다. test_privacy 가 판마다 시행일 상수를 대조하는 꼴이면 `PRIVACY_V9_EFFECTIVE` 를 더한다(`PRIVACY_V8_EFFECTIVE` 는 078 의 것).
- PR 본문에 법률 확인 항목을 적는다: ① Google 을 '제3자 제공 + 국외 이전 동의' 로 둘지, 데이터 공유를 껐으므로 '처리위탁 + 방침 공개(제28조의8 제1항 제3호)' 가 맞는지 — 이 스펙은 Clarity 와 묶으려고 동의 쪽으로 둔다. ② 3.5 의 Google 쓰임 문장. ③ 만 14세 미만 문장이 Google 에도 그대로 맞는지.

### 3.8 엣지
- 판을 올리므로 v8 에 동의한 방문자도 다시 묻는다 — 다시 동의하기 전에는 Clarity·통계·화면 이동 기록·GA 넷 다 돌지 않는다.
- GA ID 만 있고 Clarity ID 가 비었을 때: 동의 창은 뜨고 동의하면 GA 만 돈다(방침은 둘 다 적은 채 — 오래 끄면 방침에서 빼는 PR).
- 광고 차단기가 Google 스크립트를 막으면 GA 만 없고 페이지·Clarity·동의 창은 그대로다(예외를 밖으로 던지지 않는다).
- 대시보드(`/app/`)는 한 페이지 앱이다 — 페이지 조회는 페이지를 연 한 번만 센다(위 '페이지 변경' 끔). 탭 바꿈은 세지 않는다(첫 판 범위 밖 — 세려면 직접 만든 이벤트로, 이 스펙을 고쳐서).
