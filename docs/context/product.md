# product.md — 제품 정의

> 이 문서는 **목표 상태**를 쓴다. 실제 구현 여부는 `status.md` 가 말한다.

## 목적
코인 트레이더가 **한국 거래소 ↔ 해외 거래소 가격 차이(김프/역프)** 를 실시간으로 보고 차익거래 판단을 내리게 한다.
핵심 질문 3개에 한 화면에서 답한다: (1) 어느 코인이 얼마나 벌어졌나 (2) 어느 방향인가(정방향 김프 / 역프) (3) 지금 실제로 옮길 수 있나(입출금 가능·망).

## 용어
- **dom**: 국내 거래소(업비트 `upbit`, 빗썸 `bithumb`). 호가는 KRW.
- **fx**: 해외 거래소(바이낸스 `binance`). 호가는 USDT.
- **환율(rate)**: 하나은행 고시 같은 외부 환율을 쓰지 않는다. **각 국내 거래소의 KRW-USDT 마켓 호가**에서 뽑는다. 방향별로 `ask`(USDT 살 때)·`bid`(USDT 팔 때)를 구분.
- **fwd(정방향 김프 %)**: 해외에서 사서 국내에서 팔 때. 원화로 USDT 를 **사서**(rate ask) 보낸다. `(dom_bid / (fx_ask × rate_ask) − 1) × 100`
- **rev(역프 %)**: 국내에서 사서 해외에서 팔 때. 받은 USDT 를 원화로 **판다**(rate bid). `(fx_bid × rate_bid / dom_ask − 1) × 100`
  (정확한 수식·엣지는 스펙 003 에 명시)
- **선선갭**: 해외 거래소 간 **선물–선물** 가격 갭.
- **streak(구간)**: 김프/역프가 임계값 이상으로 유지된 연속 기록 구간. `/history/streaks` 가 계산한다.
- **입출금 상태**: 3-state. 가능 `true`, 중단 `false`, 모름 `null`. 코인 단위가 아니라 **망(network) 단위**로 판정한다.
- **시각 단위**: 저장소·API 의 `ts` 는 epoch **초**. API 응답의 `fetched_at`·`updated_at` 은 epoch **ms**.

## 기능 목록 (= 스펙 단위)
| 기능 | 설명 |
|---|---|
| collect | 3거래소 1초 수집, 환율 추출, 수집 상태(`/health`) |
| spreads | 전 종목 김프/역프 실시간 표, 환율, 입출금 상태, 스파크라인 |
| analysis | 단일 종목 상세·스캔·거래소 매트릭스·차익 시뮬·슬리피지·호가 |
| history | 김프 1초/1분봉 아카이브·구간 통계(streaks)·대량 백필 |
| wallet-status | 거래소 API 키로 입출금 가능 여부·망 조회 |
| web-shell | 탭 네비·KPI 스트립·테마·공용 UI |
| (gap) 선물–현물 갭, 선선갭 | 해외 선물 vs 현물. FE mock 까지만 — 비범위 |
| (health) 수집 상태 탭 | 거래소별 수집 지연·실패. `/health` 연결은 이후 스펙 |

## 비범위 (지금 단계에서 하지 않음)
- 선물 거래소·선물 갭 (바이낸스 선물, 바이비트 등 미연동)
- 주문 실행·자동매매
- 사용자 계정·인증 (단일 사용자 도구)
- 거래소 추가 (현재는 3거래소)

## 사용자
단일 사용자(개발자 본인). 모바일 대응 불필요. 브라우저 탭 하나 띄워두고 본다.
